# 민보체 / minbo font

실제 손글씨 자모를 기반으로 한 한글·영문 폰트의 **자모 조합 시험판 0.1.2**입니다. 실제 문장 필체를 기준으로 자모 간격·받침·마침표 크기를 보정할 필요가 있으며, 필체 재현 완료판은 아닙니다.

- [폰트 라이브러리](https://mant81.github.io/font-library/)
- [Android APK 릴리즈](https://github.com/mant81/font-library/releases/tag/minbo-v0.1.2)
- [웹 적용 안내](dist/USAGE.md)
- [일반 WOFF2](dist/Minbo-Regular.woff2) / [작은 글자용 WOFF2](dist/MinboSmall-Regular.woff2)
- [일반 TTF](dist/Minbo-Regular.ttf) / [작은 글자용 TTF](dist/MinboSmall-Regular.ttf)

현대 한글 11,172자, 호환 자모 51자, ASCII 95자를 포함합니다. 7px 등 15px 이하에서는 Minbo Small 보정본을 선택합니다. 픽셀 소실 검사와 모든 글자의 시각적 식별성은 다른 항목입니다.

APK는 Android 8.0 이상에서 앱 내부 미리보기를 제공합니다. 에뮬레이터에서 설치·실행·입력·7sp 전환을 검증했고, 실제 휴대폰 검증은 남아 있습니다. 시스템 기본 글꼴을 교체하지 않습니다.

원본 손글씨 이미지·서명 표본·추출 provenance·상세 검토 자료는 로컬에 보관하며 공개 저장소와 Pages에서 제외합니다. 제작 도구 사용에는 해당 로컬 입력이 필요합니다. 직접 쓴 손글씨를 바탕으로 독자 제작했습니다. 상업적 이용·수정·재배포의 허락 범위는 별도로 정하며, 아직 자유 이용 라이선스를 채택하지 않았습니다. [저작권 검토](../../docs/copyright.md)를 참조하세요.
