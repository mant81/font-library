# 민보체 / minbo font 저작권 검토

확인일: 2026-11-01 · 기준: 대한민국 · 프로젝트 이름: 한글 **민보체**, 영문 **minbo font**

## 이번 제작에 대한 판단

사용자는 실제로 손으로 쓴 글씨를 원본으로 제공했다고 밝혔다. 현재 제작 도구는 그 이미지에서 추출한 좌표를 기반으로 글리프를 조합하고 새 TTF/WOFF2를 만든다. 타사 폰트의 윤곽이나 프로그램을 가져와 이름만 바꾼 방식은 아니다. 숫자·문장부호는 원본 획의 특성을 참고해 새로 작성한 부품이다.

이 사실관계라면 타사 폰트 파일을 무단 복제한 경우와 구별된다. 다만 직접 쓴 글씨라는 사실만으로 글자 모양 전체에 독점적 저작권이 확정되거나, 자동 생성된 모든 파일이 반드시 저작물로 인정된다고 단정하지 않는다. 아래는 공식 안내에 따른 일반적인 검토이며 특정 파일의 법적 권리 유무를 확정한 판단은 아니다.

## 글자체와 폰트 파일의 구분

문화체육관광부 안내는 일반적인 글자 모양인 글자체와 디지털 폰트 파일을 구분한다. 일반적인 글자체 자체는 저작권 보호 대상으로 인정되지 않는다는 판례를 설명하고, 디지털 폰트 파일은 창작성을 갖춘 컴퓨터프로그램저작물로 보호될 수 있다고 안내한다. 감상 대상인 서예 작품 등은 별도 판단 대상이다.

## 창작·등록·권리자

저작물에 해당하는 창작물의 저작권은 별도 등록 절차 없이 창작과 함께 발생한다. 등록은 권리의 발생 조건과 다르며, 사실관계의 공시와 분쟁 시 추정 등 별도 효과가 있다. 원본 필기 파일과 날짜, 직접 수정한 글리프·조합 규칙의 이력은 로컬에 보관한다. 실제 필기자와 제작·배포자가 다른 경우에는 이용허락과 권리 귀속을 정리해야 한다. 프로젝트 이름을 정한 것만으로 특정 개인에게 권리가 양도되지는 않는다.

## 자동화 도구와 인간의 기여

이 프로젝트의 원본은 실제 손글씨이며, 이미지 자체를 생성형 AI로 대신 만든 것은 아니다. 추출·배치·빌드에는 자동화 코드가 사용된다. 한국저작권위원회의 AI 활용 저작물 안내에 맞춰 인간이 직접 선택·수정한 형태와 자동화된 부분을 구분해 기록하며, 보호 범위는 창작적 기여 등 구체적인 사실관계에 따라 판단한다. 자동화 도구를 썼다는 이유만으로 원본의 인간 기여를 부인하거나 결과물 전체의 권리를 자동 확정하지 않는다.

## 저작권과 이용허락은 별개

직접 제작했다는 출처 설명과, 다른 사람이 어떤 조건으로 사용할 수 있는지는 별개다. 공개 저장소와 다운로드 링크가 있다는 이유만으로 상업적 이용·수정·재배포까지 전부 허용한다고 표시하지 않는다. 현재는 다음과 같이 안내한다.

> 민보체 / minbo font는 직접 쓴 손글씨를 바탕으로 독자 제작한 폰트입니다. 상업적 이용·수정·재배포의 이용허락 조건은 별도로 정합니다.

사용자가 배포 조건을 선택하기 전 OFL·MIT·CC 또는 상업용 무료 라이선스를 임의로 적용하지 않는다. 폰트 제작 도구의 오픈소스 라이선스와 완성 폰트의 이용허락 조건도 구분한다. 저작권자 실명·법인명이나 특정인 소유라는 표기는 추정해서 채우지 않았다.
